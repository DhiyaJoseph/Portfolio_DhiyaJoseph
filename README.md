# Dhiya Joseph – Portfolio Website

A static portfolio site: `index.html` plus the `assets` folder (photo and resume PDF). No build step needed.

## Publish on GitHub Pages
1. Create a repository named `DhiyaJoseph.github.io` on GitHub.
2. Upload `index.html`, `README.md` and the `assets` folder to the repository root.
3. Go to **Settings → Pages**, set the source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute or two the site is live at https://dhiyajoseph.github.io

## Updating
- **Resume:** replace `assets/Dhiya_Joseph_Resume.pdf` with a new file of the same name.
- **Photo:** replace `assets/dhiya-joseph.jpg` (square image works best).
- **Project links:** add links to each project's repository inside its card in `index.html`.
